# Travel Planner Authentication UI Reference

Đây là source tham chiếu cho giao diện Authentication mới.

- App.reference.tsx chứa markup, nội dung tiếng Việt, state và interaction mẫu.
- styles.reference.css chứa toàn bộ typography, màu sắc, spacing và responsive behavior.
- Không chạy trực tiếp source React này trong ứng dụng HTML hiện tại.
- Không thêm lại cụm tab/chấm luồng trên panel ảnh.
- Khi tích hợp phải giữ nguyên form action, API endpoint, field name, CSRF token, reset token, cookie và session logic hiện có.
- Bốn trang đích: đăng nhập, đăng ký, quên mật khẩu và đặt lại mật khẩu.
- Source tham chiếu là chuẩn về hình ảnh; source hiện tại của repo là chuẩn về backend và data flow.
