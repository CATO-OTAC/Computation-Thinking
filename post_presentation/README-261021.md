## 3. Detailed Scope of AI Assistance

### 3.1 Ideation & Algorithmic Formulation
* **Heuristic Strategy Selection:** GenAI was queried to brainstorm heuristic approximations for multi-stop routing. While exact formulations like the Traveling Salesperson Problem (TSP) were identified, the decision to implement an adapted **Greedy Nearest Neighbor** approach ($O(n^2)$) to ensure fast client-side performance was evaluated and chosen by our project team.
* **Tag Matching Formulation:** AI assistance was used to brainstorm methods for scoring subjective travel vibes, which led to the creation of the normalized set-intersection matching model ($\text{MatchScore} = \frac{|U \cap D|}{|U|} \times 100\%$).

### 3.2 Slide Deck Production & Visual Design (Slides 27–46)
* **Visual Asset Generation:** AI-driven design tools were used to source and generate travel-themed illustrative graphics (such as passports, maps, travel pins, suitcases, and bicycles) to establish a cohesive visual aesthetic across slides 27 through 46.
* **Layout & Diagram Organization:** Generative assistance was utilized to optimize the visual flow of diagrams, such as:
  * The 5-step destination-known pipeline.
  * The 4-step vibe discovery workflow.
  * The data ingestion architecture diagram (connecting Google Maps API and Web Scraping to the AI normalization engine).

### 3.3 Data Engineering & Schema Conceptualization
* **JSON Schema Structuring:** GenAI was prompted to generate an initial JSON schema template for tourism POI entities (incorporating coordinates, estimated cost, category tags, and operating hours), which was subsequently adjusted to fit the constraints of our itinerary generator.

### 3.4 Report Documentation & Formatting
* **Markdown Synthesis:** An AI conversational assistant was used to help structure, format, and synthesize the technical contents of the presentation slides into a comprehensive, PDF-exportable Markdown document adhering to academic reporting standards.
